# 🐑 Río Mayo Wool Intelligence Desk
Dashboard cuantitativo para productores laneros de la Meseta Central de Chubut.
- **Fuentes de Datos:** SIPyM (MAGyP), Merino Argentino, AWEX EMI.
- **Funcionalidad:** Cálculo de precio teórico EXW (En Tranquera), monitoreo de tipo de cambio, extracción automática de PDFs oficiales.
- **Autor:** Productor Lanero - Río Mayo, Chubut.
